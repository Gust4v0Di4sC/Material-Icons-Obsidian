# Security Policy

## Supported versions

Security fixes are provided for the latest published version of Material Icons.

## Reporting a vulnerability

Please do not disclose a vulnerability in a public issue. Use [GitHub's private vulnerability reporting](https://github.com/Gust4v0Di4sC/Material-Icons-Obsidian/security/advisories/new) instead.

Include the affected version, reproduction steps, impact, and any suggested mitigation. You can expect an initial response within seven days. Confirmed reports will be coordinated privately until a fix is available.
