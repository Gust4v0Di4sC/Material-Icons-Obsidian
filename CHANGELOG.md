# Changelog

All notable changes to this project are documented here.

## [1.0.2] - 2026-10-11

### Fixed

- Replace the native file explorer icon content instead of adding a second icon.
- Preserve folder expand and collapse behavior when clicking its icon.
- Remove all injected icons, classes, observers, and pending timers when the plugin is disabled.
- Improve support for pop-out windows and legacy file explorer markup.

### Changed

- Add official Obsidian linting, strict automated review, CI, release attestations, and dependency updates.
- Publish `main.js` only as a release artifact.
- Add contribution, conduct, security, support, issue, and pull request guidance.
