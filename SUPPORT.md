# Support

For setup help or unexpected behavior:

1. Update Obsidian and Material Icons to their latest versions.
2. Restart Obsidian and reproduce the problem in the default theme when possible.
3. Review existing [issues](https://github.com/Gust4v0Di4sC/Material-Icons-Obsidian/issues).
4. If the problem remains, open a bug report and attach the requested diagnostic details. Do not attach private vault content.

Feature ideas are welcome through the feature request form. Security reports must follow [SECURITY.md](SECURITY.md).
